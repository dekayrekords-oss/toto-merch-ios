# Toto iOS target

Version 0.4.0 (6), bundle `com.meowmba.toto.avatar`. Open `Meowmba.xcodeproj`, scheme `Meowmba`. This target builds SharedKit from the parent directory and keeps the native AI, voice and memory adapters. Its home is the avatar; Flow, Desk, legacy Cozmo transport, donor deep links, Shortcuts and widget dependency are excluded from Toto navigation/launch behavior. The shared source remains for compatibility.

See `../../README.md` and `../../DELIVERY.md` for configuration, exact build commands, the pinned Lion option, asset restoration, validation and signing limitations. No production deployment or physical robot acceptance is implied.
